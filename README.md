Каждая папка — отдельный мокап, доступен на GitHub Pages по адресу:
`https://mpivkin946-crypto.github.io/mockups/<папка>/`

## Мокапы

- [tms-driver-access](tms-driver-access/) — админ-интерфейс ТМС: список водителей, история по ТК, блокировка/разблокировка УЗ (роли Логист / СБ)
